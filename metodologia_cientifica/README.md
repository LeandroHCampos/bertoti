## Sobre mim ##

Comecei minha trajetória acadêmica na Fatec, no curso de Análise e Desenvolvimento de Sistemas (ADS), onde tive contato com linguagens de marcação, como HTML e CSS, com o framework Flask e com os fundamentos da lógica de programação.

Posteriormente, migrei para o curso de Banco de Dados, buscando direcionar minha formação para o desenvolvimento backend, a gestão e a manipulação de dados. Ao longo dessa jornada, ampliei meus conhecimentos em linguagens de programação, bancos de dados e desenvolvimento de sistemas.

Hoje meu foco é o desenvolvimento backend e o trabalho com bancos de dados, e os projetos do curso são onde mais aprendo:

- Atlaz4 / GeoRural (API): API em Java com Spring Boot integrada ao Oracle Spatial, com dados geográficos, versionamento do banco com Flyway e testes automatizados.
- devops-agent: aplicação em Spring Boot 3 / Java 17.
- Data lake na nuvem: pipeline de dados orquestrado com Apache Airflow na Oracle Cloud (OCI).
- Em paralelo, trabalho como desenvolvedor backend na EBI. Utilizo GO para o desenvolvimento de integrações de sistemas, e essa rotina me ensinou a trabalhar com código em equipe, code review e versionamento com Git.

Meu objetivo é entender o porquê das coisas, e não só fazer funcionar: como o banco executa uma consulta, o que o framework faz por baixo e como projetar sistemas que sejam fáceis de manter. Também participo de maratonas de programação e eventos técnicos para acelerar esse aprendizado.

**Empresa parceira:** IPEM - Instituto de Pesos e Medidas do Estado de São Paulo

**Nome do Projeto:** Gestão de Tráfego e Viaturas

<p align="center">
  <img width="900" alt="IPEM CONTROL" src="https://github.com/user-attachments/assets/476687ba-2d7b-4d9b-88ba-2612e8b9b833" />

**Descrição do problema:** O IPEM realiza o controle de abastecimento das viaturas da Regional de São José dos Campos por meio de registros manuais. Após cada abastecimento, os condutores anotam informações como quilometragem, quantidade de combustível, valor abastecido e identificação do responsável em pranchetas físicas mantidas dentro de cada veículo. Esse processo torna demoradas a consolidação e a análise das informações, além de ser suscetível a erros e dificultar o acompanhamento do consumo de combustível, a comparação do desempenho entre as viaturas e a identificação de possíveis inconsistências nos registros.

**Solução do problema:** Desenvolvimento do Gestão de Tráfego e Viaturas, um sistema web que digitaliza o processo de controle de abastecimento das viaturas. Os condutores registram os abastecimentos de forma eletrônica, enquanto os gestores validam as informações e acompanham os dados por meio de relatórios analíticos. O sistema organiza os registros em uma base de dados estruturada, automatizando a conferência das informações e facilitando a consolidação mensal dos abastecimentos, o que traz mais agilidade, transparência e eficiência à gestão da frota.

## 2026 - 2º Semestre

**Empresa parceira:** VISIONA

**Nome do Projeto:** GeoRural DataHub

<img width="1074" alt="GeoRural DataHub" src="https://github.com/user-attachments/assets/742050b7-d47e-4643-b9cc-ec2421e037af" />

**Descrição do problema:** Dados territoriais e ambientais de propriedades rurais chegam de diversas fontes, sem padronização, validação ou rastreabilidade. Isso dificulta garantir a qualidade dos registros, saber a origem de cada indicador e acompanhar a ingestão de novos dados.

**Solução do problema:** Desenvolvimento do GeoRural DataHub, uma plataforma web com Spring Boot no back-end e Vue.js no front-end. A solução centraliza o controle, validação e governança de dados territoriais em um banco de dados relacional Oracle, permitindo a gestão de lotes de ingestão, rastreabilidade completa (data lineage) de indicadores ambientais, controle de qualidade de registros rurais através de procedimentos em PL/SQL e visualização espacial interativa e reativa com suporte a dados em tempo real via WebSocket.
